# AI 工程图纸解析（绿色便携版）

解析机械零件图/装配图 PDF：AI 提取特征参数、AI 勘误检查、入库与数据管理、智能查询。

## 使用方法

1. 双击 **启动应用.bat**（自动打开浏览器，地址 `http://127.0.0.1:8765`）
2. 首次使用先点左下角 **设置**，填入 DeepSeek API 密钥（模型默认 `deepseek-flash`），点「测试连接」
3. 四个模块：
   - **提取特征参数**：拖入 PDF → 开始 AI 提取 → 核对/修改结果 → 确认入库
   - **勘误检查**：选图纸 → 勾选检查项 → 开始勘误 → 按严重程度处理每条问题（采纳/忽略）
   - **入库与数据管理**：台账查询、编辑标题栏信息、归档/恢复/删除、查看原图、导出 CSV/JSON
   - **智能查询**：大白话提问（如"查所有 45 钢的图纸"），AI 作答并列出命中图纸；也支持材料/类别/状态筛选和导出

关闭黑色控制台窗口即停止服务。再次启动数据都在。

## 数据保存在哪

全部在本文件夹 `data/` 内：

- `data/app.db` — 图纸、参数、勘误、查询记录（SQLite）
- `data/pdfs/` — 归档的原图 PDF
- `data/config.json` — API 密钥（只存本机）

**换电脑**：把整个文件夹拷过去（U盘/网盘均可），双击 `启动应用.bat` 继续用，数据随文件夹走。
文件夹内 `runtime/` 是自带的便携 Python，目标电脑没装 Python 也能运行。

## 环境要求

- Windows 10/11（x64）
- 联网（调用 DeepSeek AI 接口、首次以外均无需下载任何东西）

## 技术说明

- 服务端：Python 标准库（零第三方依赖），`server.py` / `db.py` / `ai.py`
- 前端：原生 HTML/JS + pdf.js（已本地化在 `public/vendor/`）
- PDF → 图片在浏览器本地完成，发给 DeepSeek 的只有渲染后的页面图片
- AI 模型：`deepseek-flash`（视觉版，支持图片输入）
